# ThinkHumanly website

Static site. No build step. Open index.html in a browser to preview.

Files: index.html (the whole page), styles.css (Tailwind output, unchanged), logo.png, book covers (img1-3.jpg) and book preview pages (preview-*.jpg), CNAME (keeps thinkhumanly.co).

To add team photos: put the photo in this folder and replace the initials inside `<div class="th-avatar">` with `<img src="name.jpg" alt="Name">`.
To add statistic sources: search index.html for "TODO before launch".

Upload: GitHub repo > Add file > Upload files > drag in everything from this folder (not the folder itself) > Commit. Pages updates in 1-2 minutes.
